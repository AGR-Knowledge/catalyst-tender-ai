Catalyst_Tender_AI - Top 15 Agentic Tender Workflows (Wireframe Mock-up)
=======================================================================

How to view
  Unzip the folder and open index.html in any modern browser (Chrome, Edge,
  Safari or Firefox). The overview links to all 15 workflow screens, and the
  left-hand navigation on every screen moves between them.
  No installation or server is needed. Screens are designed at 1440 x 900.
  Fonts load from Google Fonts when online; offline, standard fallback fonts are used.

Contents
  index.html                 Overview of all 15 workflows
  WF01-Intake.html  ...  WF15-Learning.html   One screen per workflow

Notes
  All tender names, figures, dates and scores are illustrative placeholders
  (marked [Sample] or shown in brackets) and do not represent real data.
